# M11 新增页面视觉统一设计

## 目标

修复“评测中心 · 模板质量”和“系统设置”页面与现有工作台在字号、间距、按钮、卡片及空状态上的视觉差异，不改变 M11 功能和 API。

## 调整范围

- 两个新增页面不再重复显示全局“日志特征工作台”页头，仅保留各自页面标题和说明。
- 设置页沿用现有 `surface-head`、正文 10–11px、字段说明 9px、输入框 11px 和 40px 控件高度；后端地址使用等宽字体。
- 补齐统一的次级按钮样式，避免浏览器原生按钮混入；主要、次要、文字和危险操作保持一致的圆角、字号和交互态。
- 质量中心页签、工具栏、指标卡、基线卡、模板卡和 Profile 卡统一使用现有橙色主色、白色卡片、12px 圆角和紧凑间距。
- 标注工作台改为“待标注队列 + 模板簇详情”双栏，区分主操作、次操作和危险操作。
- 可疑模板提供问题类型筛选和紧凑问题卡；无结果时显示带说明的局部空状态。
- 配置对比使用 Profile A/B 选择器和逐参数对比表，替代原始 JSON 黑框，并高亮参数差异。
- 模板管理提供搜索、组件与状态筛选的数据表，保留编辑、合并、忽略/恢复、软删除和版本回滚功能。
- 发布管理显示候选、Shadow、已发布和已回滚阶段，明确人工确认与“不自动修改生产配置”的边界。
- 空状态降低视觉高度，避免无数据时出现大片无意义留白。
- 新样式使用页面作用域类，不修改全局字号比例，避免影响现有工作区。
- 900px 以下改为单列布局，按钮允许换行，模板文本保持可读。

## 验证

增加前端契约测试，确认局部类名、统一按钮、功能化页签布局及重复页头防护存在；同步更新提交版 `frontend/dist`。启动本地服务后分别检查 `/drain-quality` 和 `/settings` 的桌面与窄屏布局，并运行完整 pytest、JavaScript 语法和 Git diff 校验。
