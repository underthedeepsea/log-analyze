# M11 UI Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the initial M11 quality-center and settings layouts with the user-approved functional visual design.

**Architecture:** Preserve all API calls and governance actions in `frontend/src/app.js`; only reshape presentation and local filtering state. Scope new CSS under M11 page classes, then mirror source files to the committed runtime bundle.

**Tech Stack:** React 18 without JSX/build tools, CSS, pytest frontend contracts.

## Global Constraints

- Version is `1.17.1`; update `README.md` and `releas.md`.
- Do not alter Drain Quality API behavior or send raw logs to the frontend.
- Render all model and template text as text nodes; do not use raw HTML injection.
- Keep the committed `frontend/dist` synchronized without adding Vite, npm scripts, or a CDN.
